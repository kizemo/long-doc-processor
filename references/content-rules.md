# 内容净化规则（直播 / 培训音视频转录专用）

> 适用场景：直播带货、付费课程、企业内训、公开课等"讲师口述转文字稿"的净化。
> 学术论文、技术规范、流程文档净化**不强制使用**本文件。
>
> 本文件是 `references/purification-prompt.md` 的**前置策略**；执行 Step 2 前先读本文件，再读 Prompt。

---

## 1. 实质性内容定义（8 类）

只保留以下 8 类内容，其余一律删除：

| # | 类别 | 含义 | 示例 |
|---|------|------|------|
| 1 | **理论** | 学科基础原理、模型、公式 | "边际效用递减规律" |
| 2 | **概念** | 术语定义、分类标准、命名 | "人群标签 = 平台给用户打的属性标记" |
| 3 | **实操** | 可执行的步骤、操作方法 | "Step 1：先建计划；Step 2：设置出价" |
| 4 | **推导逻辑** | 因果链、推理过程、对比论证 | "A 之所以导致 B，是因为 C；与 D 的区别在于 E" |
| 5 | **案例** | 真实店铺/品牌/事件的完整要素（背景/做法/结果） | "某母婴店铺通过 X 调整，月 GMV 从 Y 提升到 Z" |
| 6 | **数据** | 数值、比例、增长率、KPI、时间节点 | "2026 年标签权重从 30% 提升到 45%" |
| 7 | **分析** | 对数据/现象的解读、归因、趋势判断 | "这说明流量结构正在向内容场倾斜" |
| 8 | **观点** | 讲师基于经验的判断、立场、建议 | "中小卖家不建议一开始就投信息流" |

> **判断口诀**：删掉后**对不在直播间的读者是否还有信息价值**？没有则删。

## 2. 必须删除的内容（无关内容）

### 2.1 培训机构 / 讲师 / 课程介绍

- "我们公司是 XX 培训机构的"、"我们专注于 XX 领域 N 年"
- "我是 XX 老师 / 讲师，我叫 XX，我做 XX 已经 N 年"
- "这门课原价 N 元，今天只要 M 元"、"扫码加入我们" 等促销/招生信息
- 课程目录预告、上课安排、下节课预告

- "下节课我们会讲 W"

- "没听清扣 1"、"同意的打 666"

- "老师好，我是做 XX 类目的"（课堂互动寒暄）

## 3. 引导语去除

直接陈述实质性内容，**禁止使用**以下引导语：

| 引导语类型 | 反例（禁止） | 正例（应改为） |
|---|---|---|
| 引用讲师观点 | "讲师认为标签权重很重要" | "标签权重对自然搜索流量有显著影响" |
| 引用讲师案例 | "讲师分享了某母婴店的案例" | "某母婴店通过调整人群标签，3 个月内 GMV 提升 40%" |
| 引用讲师建议 | "讲师建议大家先做人群测试" | "建议先做人群测试，再设置出价" |
| 引用讲师强调 | "讲师反复强调，直通车核心是人群匹配" | "直通车核心是人群匹配，而非单纯出价" |

**判定原则**：讲了什么 ≠ 谁说了什么。读者需要的是**信息本身**，不是"谁在说"。

## 4. 口语填充词词典（必须清理）

下列词在直播/培训中频繁出现但不承载信息：

| 类别 | 词表 |
|------|------|
| 应答/确认 | 对、嗯、啊、哦、好的、好、行、OK、yes、no |
| 询问/反问 | 对不对、对吧、是不是、懂了吗、听明白了吗、懂我意思吧、你说对不对 |
| 口头禅 | 就是说、然后呢、那么、其实呢、反过来说、话又说回来、怎么说呢 |
| 引导/铺垫 | 我们看一下、接下来啊、那我们讲、好那、那就这样、大家看一下 |
| 强调/重复 | 非常、特别、真的、确实、一定要、必须（纯修饰无新意时） |
| 模糊量词 | 一点、一些、大概、可能（无量化价值时） |

> 同一口头禅 **≥ 3 次重复** 整段删除（不保留 1 次的"标记"）。

## 5. 判断三问（每次大段删除前的内部核查）

主代理或子代理在删除任一段落前，自问三个问题：

1. **信息损失问**：删掉这段对一个不在直播间的读者有没有信息损失？
   - 没有 → 删；
2. **目标帮助问**：这段是否帮助老板/学员理解"怎么做电商"或"未来怎么走"？
   - 否则 → 删；
3. **叙事紧凑问**：删掉后叙事是否更紧凑？
   - 紧凑化是净化目标 → 倾向删。

> 三问任一答案为"否"或"是"时，优先删除。

## 6. 课程广告 / 讲师自介的渐进式规则

| 出现次数 | 处理 |
|---------|------|
| 第 1 次 | **可保留**（建立权威，让读者知道讲师背景） |
| 第 2–N 次 | **必须删除**（重复即营销） |

> 例："我叫 X，做电商 12 年，专注 XX 领域" → 首次出现保留建立信任；后文每次重复均删除。

## 7. 与 purification-prompt.md 的协作

执行 Phase 1 Step 2 的标准流程：

```
1. 读 references/content-rules.md（本文件）   ← 理解"保留什么、删除什么"
2. 读 references/purification-prompt.md       ← 获取净化 Prompt 模板
3. 按 Prompt 执行 4 大类噪声清理
4. 按本文件 8 类实质内容筛选保留
5. 按本文件 2–6 节规则删除无关/广告/口语/引导语
6. 自检 5 类资产完整性 + 8 类实质内容覆盖率
7. 写入末尾 ## 统计 区块（含清理计数与保留率说明）
```
