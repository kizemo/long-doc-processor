# 统一验收与退出条件

所有阶段的验收规则与退出条件以本文件为唯一权威来源；其他 reference 仅引用不复制。

## 通用退出条件

```text
执行 → 验收 → 通过则继续
             ↓
          失败则最多修正 2 次
             ↓
      连续 3 次同类失败 → 暂停并请求人工介入
```

## Phase 0 · 目录与命名决策（Step 0.5 / 0.6）· 3 项

1. `OUT` 已由用户在三个选项中选定，绝对路径写入 handoff；
2. `AV_DIR/tmp/` 已创建，所有中间文件与脚本都落在这里；
3. `OUTPUT_STEM` 已确认，交付物文件名与之一致。

## Phase 0 内容抽查 · 4 项

1. 表格已转为 Markdown 表格格式；
2. 段落结构保留，标题层级正确；
3. 字符数与原始差异 < 5%；
4. 图片位置已标注。

## Phase 1 Step 2 · 14 项

1. 4 类噪声已删除（纪律语/引导语/寒暄/口语填充）；
2. 人称转换正确（第一人称→讲师，你们→学员）；
3. 广告与水话段已删除；
4. 5 类资产完整保留（概念/案例/数据/逻辑/表格）；
5. 使用 4 级标题；
6. 每个 H3 至少 2 段正文；
7. 保留率 ≥ 55%（不达则必须解释）；
8. 末尾 `<!-- CURRENT_BATCH_END -->` 已就位；
9. **8 类实质内容覆盖**（理论/概念/实操/推导逻辑/案例/数据/分析/观点，详见 `references/content-rules.md` §1）；
10. **引导语已去除**（无"讲师说 / 讲师认为 / 讲师提到 / 讲师分享 / 讲师强调"等，详见 `content-rules.md` §3）；
11. **培训机构 / 讲师 / 课程介绍已去除**（课程计划/课堂纪律/上课安排已删除，详见 `content-rules.md` §2.1–§2.2）；
12. **直播广告 7 类已扫描删除**（含直播间互动 100% 删除，详见 `content-rules.md` §2.3–§2.4）；
13. **口语填充词词典已清理**（同口头禅 ≥ 3 次重复整段删除，详见 `content-rules.md` §4）；
14. **课程广告 / 讲师自介按渐进式规则处理**（首次可保留建立权威，后续重复删除，详见 `content-rules.md` §6）。

## Phase 1 Step 4 · 6 项

1. H1 编号连续；
2. 每个 H1 下 H2 编号连续；
3. 每个 H2 下 H3 编号连续；
4. 无编号标题数 = 0；
5. 无旧编号残留；
6. 无 `h2_chapter_mismatches`。

## Phase 2 Step 7 · 4 项

1. 章节映射正确；
2. 无遗漏；
3. 无重复；
4. 顺序正确。

## Phase 2 Step 10 · 16 项（合并后结构自检）

1. H1/H2/H3/H4 数量符合预期；
2. H2 编号连续（1-N，无跳跃）；
3. 每个 H2 下 H3 编号连续；
4. 每个 H3 下 H4 编号连续；
5. 空行数 ≤ 文档数 + 10；
6. 无编号 H2 = 0；
7. 无编号 H3 = 0；
8. H4 可接受无编号（视场景定）；
9. 总字符数偏差 ≤ 5%；
10. 文档开头有且仅有一个 H1；
11. 旧编号已清除；
12. 无 `## 统计` 区块残留；
13. H2 编号唯一；
14. H3 编号唯一；
15. H4 编号唯一；
16. 无 `h2_chapter_mismatches`。

## Phase 2.5 结构重排（v4.24 新增）· 6 项

1. **H3 总量达标**：全文 H3 ≤ `max(20, 字符数/3000)`（19.4 万字符 ⇒ ≤ 66）；
2. **单章 H3 达标**：任一 H2 下 H3 ≤ 18；
3. **H4 已启用**：文档存在 H4，且每个 H3 下 H4 ≤ 18；
4. **守恒**：分组计划 idx 并集 = 原 H3 全集，无重复、无遗漏、章节归属正确、序号递增；
5. **无场次标签**：任何标题不含 `第一天上午 / 第一天下午 / 第二天上午 / 第二天下午` 等 ASR 场次前缀；
6. **每组有导语**：新 H3 下第一个元素是 1–2 句 `intro` 正文段，而不是直接进 H4。

> 工具：`scripts/restructure_outline.py --audit` 诊断、`--plan-out` 导出清单、
> `--apply-plan` 校验并应用（`--check-only` 只校验不写盘）。
> 完整流程、四步操作与陷阱表见 `references/phase-2.5-restructure.md`。

## Phase 3 · 7 项（HTML 输出）

17. HTML 文件可解析（无语法错误）；
17b. **无 YAML frontmatter 残留**（`markdown_to_html.py` 已自动剥离输入 markdown 头部的 `---` 元数据块；`verify_html.py` 17b 项确认无 `<p>---</p>` 或 `<p>title:/source:/date:/author:` 等伪段落）；
18. `<title>` 与首个 H1 一致；
19. 所有 `<img>` 引用的文件存在；
20. 所有 `<img>` 含 `alt` 属性；
21. `img/` 子目录与 HTML 在同一父目录；
22. 顶层 H1 有且仅有一个。

## OCR 改写 · 3 项

23. 冲突项均以 OCR 文本为准；
24. 补充项已插入并标 `[来源：图片OCR]`；
25. 差异清单写入本文件报告行。

## 配图生成 · 4 项

26. 必要性判定按清单逐项比对；
27. 生成图保存到 `img/`；
28. 文件名遵循 `fig-X-Y-语义.png`；
29. 不覆盖原始输入图。

## 视频关键帧再生 · 5 项

30. 关键帧 OCR 抽取完成；
31. 重要辅助帧已按 4 类清单判定（概念/理论/实操/OCR 强相关）；
32. 装饰帧（讲师头像/片头片尾/空白）已跳过，未入 `img/`；
33. 重新生成的图片保存到 `img/`，命名遵循 `fig-keyframe-NN.png`；
34. HTML 中按 OCR 文本与正文匹配位置插入，含 `alt` 与 `data-source="generated-from-keyframe"`。

## 原帧智能裁剪与插入（Phase 1.8 · v4.19 新增）· 4 项

35. **cleaned.md 中 `![]()` 引用数 ≤ 8**（8 张硬上限，超过则截断；qa-gates 强制数字 ≥ 0 且 ≤ 8）；
36. **`img/fig-crop-*.jpg` 文件存在且每张 ≤ 200KB**（JPEG quality=85 + optimize=True 强制保证，超则 quality 递减重压）；
37. **每张图对应 H3 在 cleaned.md 中存在**（h3_target 必为 cleaned.md 中实际存在的 H3 编号，缺失则该帧跳过，图片保留在 `img/` 但不入 md）；
38. **每张图 caption ≥ 5 字**（非空占位，防止 LLM 返回空字符串或单字 caption）。

> 完整定义与失败模式处理见 `references/phase-1.8-frame-crop.md` §6 硬约束 + §8 验收。

## 配图视觉规范（人工验收，原 35-38，v4.19 起重编号为 39-42）· 4 项

39. **文字未溢出容器**（容器宽度 ≥ 文字宽度 × 1.2；长文本自动换行）；
40. **文字与背景对比度 ≥ 4.5:1**（深色背景配浅色文字，浅色背景配深色文字）；
41. **字号充足**（标题 ≥ 36px / 正文 ≥ 24px）；
42. **禁止"深+深"或"浅+浅"组合**。

> 此 4 项由人工验收覆盖，详见 `references/image-style.md` §5。`scripts/generate_image.py` 已自动注入视觉规范段到每个 prompt。

## 整体退出

所有阶段验收通过后，最终会话总结（**非文档内**）必须包含：

- HTML 实际输出路径；
- `img/` 中已生成的图片清单（或明确说明无配图）；
- **净化统计**（4 类噪声清理估算、字符数、保留率、保留率异常说明）—— **不得写入最终 HTML**；
- 任何警告项与残留的人工介入建议。

> 净化统计从 `references/purification-prompt.md` "净化统计" 节取数；最终 HTML 不含 `## 统计` 区块（对应 Step 10 #12）。
