# 图片视觉规范（v4.2 新增）

> 适用于 `scripts/generate_image.py` 与 MiniMax-M3 / 本地 SDXL 出图的统一视觉约束。
> 主代理在构造 prompt 时必须遵循本规范；脚本会自动注入末尾约束段。

---

## 1. 文字溢出修复

**问题**：配图中文字超出容器边界，文字被裁剪或溢出到容器外。

### 规则

| 项 | 要求 |
|---|---|
| 容器宽度 | ≥ 文字预估宽度 × 1.2（至少留 20% 余量） |
| 长文本 | >15 中文字符 或 >30 英文字符 → **必须自动换行** |
| 容器高度 | 随行数动态扩展；**禁止固定高度截断** |
| 文字与容器边距 | ≥ 文字高度的 1.5 倍 |
| 字号 | 标题 ≥ 36px；正文 ≥ 24px |

### Prompt 约束模板

```text
- 文字容器宽度 ≥ 文字宽度 × 1.2
- 文字自动换行，禁止单行溢出
- 容器高度自适应内容，禁止固定高度截断
- 文字与容器边距 ≥ 1.5 倍行距
```

## 2. 深色背景与浅色文字对比

**问题**：深色背景上使用深色文字，对比度不足导致看不清。

### 规则

| 背景色 | 推荐文字色 | 禁止 |
|--------|-----------|------|
| 深色（#000–#333）| 白色 `#FFFFFF` 或 浅灰 `#F0F0F0` | 黑色、深灰、深蓝、深绿 |
| 中色（#666–#999）| 白色或深色都可 | 避免同色系中等明度 |
| 浅色（#EEE–#FFF）| 深色 `#222` / `#003070` | 浅灰、白色、米色 |

### 对比度要求

- 文字与背景**亮度差 ≥ 4.5:1**（WCAG AA 标准）；
- 大字体（≥ 28px）允许 ≥ 3:1；
- 严格禁止"深色文字 + 深色背景"组合；
- 严格禁止"浅色文字 + 浅色背景"组合。

### Prompt 约束模板

```text
- 深色背景必须配浅色文字（白色 #FFFFFF 或 浅灰 #F0F0F0）
- 浅色背景必须配深色文字（深蓝 #003070 或 深灰 #222）
- 文字与背景对比度 ≥ 4.5:1
- 禁止深色文字配深色背景；禁止浅色文字配浅色背景
```

## 3. 统一 Prompt 结构（必含）

`generate_image.py` 调用时，prompt 必须按以下结构组织：

```text
[1. 主题描述]
[2. 布局与容器描述]

【视觉规范（自动注入）】
- 文字容器宽度 ≥ 文字宽度 × 1.2
- 长文本自动换行，禁止单行溢出
- 容器高度自适应，禁止固定高度截断
- 文字与容器边距 ≥ 1.5 倍行距
- 深色背景用浅色文字，浅色背景用深色文字
- 对比度 ≥ 4.5:1
- 字号：标题 ≥ 36px，正文 ≥ 24px
```

> `scripts/generate_image.py` 会自动追加【视觉规范】段，无需手动编写。

---

## 4. 出图前自检清单（主代理）

主代理调用 `generate_image.py` 前逐项打勾：

- [ ] 主题描述清晰（场景/对象/意图）
- [ ] 布局描述明确（横版/竖版/卡片/网格）
- [ ] 文字内容已预估字符数与宽度
- [ ] 容器已规划并预留 ≥ 20% 余量
- [ ] 背景色与文字色对比度 ≥ 4.5:1
- [ ] 已避免"深+深"、"浅+浅"组合
- [ ] 已规划字号（标题 ≥ 36px / 正文 ≥ 24px）

---

## 5. 出图后人工验收（手动）

由于图片视觉无法由脚本自动验证，主代理或用户在拿到图片后必须人工检查：

| 检查项 | 失败处理 |
|--------|---------|
| 文字是否完整出现在容器内，未溢出 | 重新出图，prompt 加 `"严格不溢出"` |
| 文字是否清晰可读，对比度充足 | 重新出图，prompt 指定更高对比配色 |
| 字号是否足够阅读 | 重新出图，prompt 加 `"字号 ≥ 48px"` |
| 整体配色是否与文档主题协调 | 重新出图，prompt 指定色值 |
